МП «ТАЙНЫЙ ДОКУМЕНТ» — GitHub Pages + Firebase Realtime

Это версия с настоящей общей доской:
- все улики изначально скрыты;
- просмотр доступен всем;
- редактирование доступно только после ввода общего пароля;
- саморегистрация игроков не нужна;
- включение/скрытие улик синхронизируется у всех;
- перемещение, поворот и порядок слоёв синхронизируются у всех;
- сайт можно бесплатно разместить на GitHub Pages.

ПЕРЕД ПУБЛИКАЦИЕЙ:
Открой SETUP_GUIDE.html и выполни шаги настройки Firebase.

Файлы:
index.html
styles.css
script.js
firebase-config.js
database.rules.json
SETUP_GUIDE.html
QUICK_SETUP.txt
assets/

Важно: полностью без первоначальной настройки Firebase realtime-синхронизация невозможна, потому что база должна принадлежать вашему Firebase-проекту.

НОВАЯ СИСТЕМА РОЛЕЙ:
- viewer: только просмотр;
- player@board.example: движение и поворот, без доступа к включению/скрытию;
- editor@board.example: полный админ-доступ.

После обновления обязательно:
1. создать player@board.example в Firebase Authentication;
2. вставить новые database.rules.json в Realtime Database -> Rules -> Publish.

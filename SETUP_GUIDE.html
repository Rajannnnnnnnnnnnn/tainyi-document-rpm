Настройка общей realtime-доски

После этой настройки сайт можно хранить бесплатно на GitHub Pages. Firebase будет только синхронизировать улики между всеми открытыми страницами.

После настройки: администратор включает улику → она появляется у всех; редактор двигает или поворачивает фото → это сразу видят остальные пользователи.

1. Создай проект Firebase

Открой Firebase Console → Create a project → создай обычный проект. Google Analytics для этого сайта не обязателен.

2. Добавь Web App

В Firebase Project Overview нажми значок </> → зарегистрируй Web App.
Firebase покажет объект firebaseConfig.

3. Заполни firebase-config.js

Открой файл firebase-config.js из архива и замени только значения с PASTE_... на значения своего Firebase. 
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...",
  databaseURL: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
Важно: Firebase Web config не является паролем от Firebase. Он предназначен для размещения в клиентском сайте. Защита записи выполняется Database Rules + Authentication.

4. Включи Realtime Database

Firebase Console → Build → Realtime Database → Create Database.
После создания открой вкладку Rules.

Скопируй туда содержимое файла database.rules.json из архива:

{
  "rules": {
    "boards": {
      "main": {
        ".read": true,
        ".write": "auth != null && auth.token.email == 'editor@board.example'"
      }
    }
  }
}

Нажми Publish.

5. Создай одного общего редактора

Firebase Console → Build → Authentication → Get started.
Во вкладке Sign-in method включи Email/Password.

Затем открой Users → Add user и создай ДВА аккаунта: 
1) Администратор
Email: editor@board.example
Password: отдельный пароль администратора

2) Участники
Email: player@board.example
Password: общий пароль для проверенных участников

Например, пароль можешь сделать Murphy47RPM!. Администратор входит через кнопку ⚙ и видит панель включения/скрытия улик. Участники входят через кнопку ✋ и могут только перемещать и поворачивать уже открытые улики. Email сайт подставляет сам.

6. Разреши адрес GitHub Pages

После публикации сайта узнай свой адрес вида:
https://USERNAME.github.io/REPOSITORY/

В Firebase Authentication открой Settings → Authorized domains и добавь:
USERNAME.github.io

7. Залей сайт на GitHub

Создай новый репозиторий GitHub.
Распакуй ZIP и загрузи содержимое папки в корень репозитория: index.html, script.js, styles.css, firebase-config.js, assets и т.д.

Затем:

GitHub → Repository → Settings → Pages
Source: Deploy from a branch
Branch: main
Folder: / (root)
Save

8. Первый запуск

Открой опубликованный сайт.
Администратор нажимает ⚙ и вводит пароль editor@board.example.
Проверенные участники нажимают ✋ и вводят пароль player@board.example.

При первом входе сайт сам создаст структуру доски в Realtime Database. По умолчанию все улики скрыты.

Как пользоваться во время МП

Обычный игрок: открывает ссылку и видит общую доску. Может двигать/масштабировать сам вид доски, но не улики.

Проверенный пользователь: нажимает ⚙ → вводит общий пароль. После этого может:
• включать/скрывать улики в админ-панели;
• перетаскивать фотографии и документы;
• поворачивать выбранный объект Q/E;
• поворачивать Alt + колесо мыши;
• сбрасывать расположение.

Все эти изменения синхронизируются у всех пользователей почти сразу.

Если что-то не работает

  • Firebase не настроен — проверь firebase-config.js.
  • Вход не принимает пароль — проверь Authentication → Users и Email/Password.
  • Вход есть, но двигать нельзя — проверь Database Rules.
  • На GitHub вход блокируется — добавь USERNAME.github.io в Authorized domains.
  • databaseURL отсутствует в config — скопируй его со страницы Realtime Database.

На этом всё. После первоначальной настройки код больше менять не нужно. Управление уликами происходит прямо на сайте через ⚙.

Роли на сайте

Обычный посетитель: только смотрит.

Участник ✋: может двигать и поворачивать открытые улики. Не видит админ-панель и не может включать/скрывать доказательства.

Администратор ⚙: может всё: двигать, поворачивать, включать и скрывать улики, а также сбрасывать расположение.
